# Плавная работа сессий — 2 октября 2026

Существующий постоянный профиль и настоящий Selenium Chrome сохраняются. Подмена
browser fingerprint, сокрытие WebDriver, обход CAPTCHA, автолайки и действия для
искусственного «прогрева» не добавлены. Это улучшение выполнения задач и контроля
нагрузки, а не гарантия прохождения детектирования Meta.

Изменения:
- Уже видимый элемент не прокручивается повторно перед действием.
- Обычная вставка через буфер остаётся основной. При её отказе клавиатура вводит
  короткие группы текста с паузами на границах; пробелы и переносы сохраняются.
  Перед каждой группой проверяются фокус, остаток времени и смена IP.
- После ввода предусмотрена пауза для проверки полного текста. Между подтверждёнными
  ответами цепочки есть короткая пауза. Неопределённая отправка по-прежнему не повторяется.
- Лента читается шагами примерно по половине экрана, максимум четыре прокрутки.
  Каждый этап сохраняет кандидатов до удаления React-карточек из DOM. Чтение
  прекращается после пяти подходящих постов или двух этапов без новых кандидатов.
- После прокрутки ожидаются новые карточки; повторная загрузка при застое не запускается.
  Проверки CAPTCHA/ограничений выполняются на каждом этапе чтения и до refresh пустой ленты.
- Новые паузы проверяют лимит сессии и смену IP каждые 250 мс. Контекст хранится
  на экземпляре браузера, чтобы параллельные задачи не смешивали ограничения.
- Удалён неиспользуемый метод случайных лайков. Не добавлены действия от имени
  пользователей сверх чтения ленты и их запланированных публикаций.

Проверки: три новых сценария (остановка пауз, потеря фокуса и сохранность текста,
сохранение карточек при виртуализации), плюс три существующих сценария полного
текста и неопределённой публикации цепочки. Всего шесть, без реальных действий в Meta.
Изменения на реальных клиентских аккаунтах не проверялись; за результатами можно
судить по штатным операциям после выкладки. Рост охватов или уменьшение банов не доказаны.
