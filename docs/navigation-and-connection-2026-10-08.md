# Понятное меню и подключение Threads — 8 октября 2026

Задача: убрать путаницу между общими разделами и выбранным проектом, вернуть доступ к аккаунтам и настройкам, упростить подключение без ложных обещаний переноса входа по обычной ссылке.

## Обязательный объём

- [x] Общее меню: проекты, все аккаунты, настройки сервиса.
- [x] Меню проекта: обзор, посты, настройки выбранного проекта.
- [x] Переключатель показывает реальный раздел, а не последний проект из памяти.
- [x] Возврат в общее меню не перенаправляет обратно в проект.
- [x] Общие настройки: аккаунты, шаблон стиля, оплата, предпочтения сообщений.
- [x] Сохранённый шаблон стиля остаётся доступен на `/app/settings/style`.
- [x] Окно Threads принимает обычный ввод с клавиатуры и вставку текста на компьютере.
- [x] Ввод передаётся последовательно, символы собираются в короткие пакеты. Ошибка отменяет последующие накопленные действия; повторного автоматического ввода нет.
- [x] Для телефона остаётся ручной ввод через раскрываемый блок.
- [x] Импорт — запасной способ: пошаговое объяснение, загрузка файла до 1 МБ, поле без технического примера.
- [x] При повторных проверках есть объяснение и переход к альтернативному подключению.
- [x] Обновление входа доступно в «Все аккаунты», в том числе у аккаунтов без проекта. Сохранение данных не снимает паузу.
- [x] Проверка переходов на компьютере и телефоне: общий раздел не уводит в сохранённый проект; меню каждого режима ведёт по правильным адресам.
- [x] Проверка обычного ввода и вставки: запросы идут последовательно; после ошибки ввод останавливается до явного продолжения пользователем.
- [x] Проверка загрузки файла и обновления аккаунта без проекта на изолированных данных.
- [x] Финальная сборка: проверка TypeScript, клиентская и серверная сборки, prerender и сохранение настройки Метрики.
- [ ] Публикация и проверка доступности новой версии.

## Ограничения

Изменения упрощают интерфейс и ввод, но не гарантируют прохождение проверок Meta/reCAPTCHA. Обычное открытие Threads на устройстве посетителя не передаёт cookies сервису. Официальный возврат с разрешением доступа через OAuth выдаёт API-токен; это отдельный способ подключения и отдельный адаптер публикации, не сессия для текущего браузерного адаптера. Он не внедряется в этом исправлении.

Рабочие прокси, подписки, расписания, данные входа и настройки аккаунтов не меняются. Профиль arsevenars остаётся на паузе. Настоящие входы и публикации для проверки интерфейса не выполняются.
