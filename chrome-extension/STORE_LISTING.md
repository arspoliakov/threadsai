# Данные для Chrome Web Store

## Название

ThreadsGo: подключение профиля

## Краткое описание

Подключает открытый профиль Threads к ThreadsGo в один клик без ручного экспорта cookies.

## Единственная цель расширения

Расширение безопасно передает cookies открытой пользовательской сессии Threads в аккаунт пользователя ThreadsGo после его явного нажатия кнопки подключения.

## Обоснование разрешений

### `cookies`

Нужно для чтения cookies открытой сессии Threads. Чтение происходит только после явного нажатия пользователем кнопки «Подключить открытый профиль Threads».

### Доступ к `threads.net` и `threads.com`

Нужен исключительно для получения cookies Threads. Расширение не читает содержимое страниц Threads и не изменяет их.

### Доступ к `threadsgo.ru`

Нужен для связи с кнопкой подключения в кабинете ThreadsGo и отправки cookies напрямую на API ThreadsGo по одноразовому коду.

## Работа с пользовательскими данными

- Обрабатываются только cookies Threads.
- Cookies передаются только на `https://threadsgo.ru`.
- Передача выполняется по HTTPS и одноразовому коду, действующему 10 минут.
- Данные не используются для рекламы, аналитики, кредитования или перепродажи.
- Данные не передаются третьим лицам.
- Расширение не собирает историю браузера.
- Расширение не выполняет удаленный код.

## Privacy policy URL

`https://threadsgo.ru/terms#privacy`

## Инструкция для модератора

1. Установить расширение.
2. Открыть `https://www.threads.com` и войти в тестовый профиль Threads.
3. Войти в `https://threadsgo.ru`.
4. Открыть страницу «Аккаунты».
5. Нажать «Добавить профиль», затем «Подключить открытый профиль Threads».
6. Убедиться, что профиль появился в списке ThreadsGo.
