# ThreadsGo Chrome Extension

Расширение передаёт cookies открытой сессии Threads в ThreadsGo по одноразовому коду.

## Локальная установка

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `chrome-extension`.
5. Перезагрузите открытую вкладку ThreadsGo.

## Разрешения

- `cookies`: чтение cookies Threads только после нажатия пользователем кнопки подключения.
- Доступ к `threads.net` и `threads.com`: получение cookies открытой сессии Threads.
- Доступ к `threadsgo.ru`: передача cookies по одноразовому коду и связь с кнопкой на сайте.

Расширение не собирает данные в фоне и не передаёт cookies третьим лицам.
