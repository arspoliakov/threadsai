# Единый раздел администратора — 3 октября 2026

Главный раздел: https://threadsgo.ru/app/admin
Владелец видит кнопку «Админка» в шапке кабинета рядом с профилем и пункт в меню профиля. На компьютере и телефоне используется один раздел с вкладками.

- Дашборд: пользователи, подписки, регистрации за 7 дней, создание проектов, первая публикация, количество проектов и аккаунтов.
- Состояние заданий, генерации, аккаунтов и обработки уведомлений Tribute.
- Пользователи и подписки: поиск по имени, нику, Telegram ID; активность доступа, тариф, оплаченный и подарочный срок, проекты, аккаунты, настройки рассылок. Список разбит на страницы.
- Прокси и хранилище: существующая защищённая диагностика, расход, настройки и назначения.
- Рассылки: кампании, сегменты, доставка и автоматическая помощь со стартом.

Все API /admin защищены проверкой подписанного Telegram JWT, ADMIN_TG_ID и совпадения профиля в базе. Общий WEB_ADMIN_TOKEN больше не открывает этот раздел. Интерфейс проверяет роль через /auth/me, скрывает вход обычным пользователям и не загружает содержимое админки при отсутствии роли. Основная защита на сервере, а не в интерфейсе.

Дашборд не выдаёт сохранённые пароли, cookies, содержимое профилей браузера или ключи поставщиков. Подписки не используются для вычисления выручки: текущая активность не подтверждает новую оплату. Наличие настроек интеграции не выдаётся за проверку её доступности.

Проверки: отдельный аккаунт получает 403, общий токен получает 403, подмена Telegram ID без совпадающего профиля не проходит, владелец видит данные. Никаких сообщений пользователям и изменений их подписок при проверке нет.
