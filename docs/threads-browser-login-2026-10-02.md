# Подключение нового Threads-профиля через браузер

Реализован альтернативный способ в разделе «Профили» → «Войти через браузер». Пользователь указывает username, открывает отдельное окно, вручную входит в Threads и подтверждает подключение. Импорт файла/JSON остаётся доступным. Реализация изучена в `C:/Проекты/Тредс Олеся/app/owner_window.py`; в ThreadsGo адаптирована под tenant JWT, шифрование и собственный пул прокси. Пароли не вводятся агентом, проверки Meta не обходятся.

Сервер запускает отдельный временный Chrome с назначенным прокси. Изображение JPEG отдаётся без кеширования только с JWT владельца и отдельным случайным ключом окна в заголовке; ключ отсутствует в URL. Действия ограничены кликами внутри 1024×768, коротким текстом, разрешёнными клавишами и прокруткой. Окно действует 15 минут и закрывается при завершении, отмене, остановке сервиса или таймауте. Временный профиль и расширение прокси удаляются при закрытии. Сохранение паролей браузером отключено.

Перед сохранением проверяются профиль в навигации Threads, отсутствие экрана входа/проверки, лимит тарифа, отсутствие дубликата и доступность первоначального порта. Публичный адрес /@username не считается подтверждением владельца. Cookies посторонних сайтов отбрасываются, сессия шифруется существующим механизмом. Новый профиль появляется свободным, не привязанным к проекту: само подключение ничего не публикует. При занятости первоначального порта пользователь повторяет вход, вместо скрытой смены подключения.

Для первого выпуска одновременно открывается одно окно на сервере, чтобы не исчерпать память. Это ограничение отображается сообщением о занятости. Обновление уже существующей сессии пока остаётся через карточку и импорт; не создаём дубликат подключённого профиля.

Проверки: сборка frontend, три целевых теста (владелец/ключ/срок, отказ при несовпадении профиля и фильтрация cookies, ограничения команд), просмотр модального окна в демонстрационном кабинете. На рабочем сервере отдельно подтверждены запуск браузера через свободный порт и получение JPEG (61 096 байт); диагностическое окно закрыто, аккаунт не создавался. Реальный вход с паролем и проверками конкретного владельца не выполнялся: его пользователь проходит сам. Успешный запуск браузера не подтверждает отсутствие ограничений Meta.
